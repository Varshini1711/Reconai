How ReconAI Reasons

Deterministic logic (Layers 1–4) handles exact matches, fuzzy merchant-name variants, and arithmetic that can be verified with certainty — batching, fees, refunds, split payouts. Only genuinely ambiguous or unexplained cases reach Layer 5, where a real LLM agent investigates using controlled tools, proposes a decision, and is forced through an explicit self-critique step before finalizing. AI is used where judgment is actually needed — not applied to every record.
